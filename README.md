# Nightjar replay

A turn-by-turn replay of a controlled 2-player Wingspan game (digital edition, Oceania player mats) set up so that
one player scores as much as possible.

Expansions: base game, Swift Start promo pack, European, Oceania, Asia. Fan packs: British Birds, Additional Asian
Avians, Birds of Continental Europe. Deck order stacked; dice rolls assumed favourable.

The main idea: every non-forest bird is taken out of the deck. After that, each activation of the Great Eared
Nightjar's power, copied and repeated on the scoring player's board, caches one grub for every forest bird in the
deck and the discard pile.

**Page:** https://zarypov.github.io/nightjar-replay/

The page shows both boards at every turn, each turn's log, the deck, the tray and the discard pile. Use the
buttons or the arrow keys to step through the turns, or link to a turn with `#turn-40`. The turn buttons fold away above the
boards, and the setup notes fold away below them.

`index.html` is self-contained: the game data and icons are inside the file. It loads only its fonts from
Google Fonts.
